# Reference face images

Reference face images are not distributed in this repository. Place two clear images for each identity in this directory using the paths recorded in `manifests/speakers.csv`, for example:

```text
references/id000001_1.jpg
references/id000001_2.jpg
```

Only use images that you are legally allowed to process. The exact reference images used in the thesis should remain in restricted project storage unless their redistribution rights have been confirmed.

# Model files

Model weights are not distributed in this repository.

- InsightFace downloads the `buffalo_l` model pack through its normal setup process.
- Run `bash scripts/setup_syncnet.sh` to download the official SyncNet code and weights.
- Speaker-recognition baseline weights must be obtained from the original `voxceleb_trainer` project.

Always review the licence and usage conditions of each external model before redistribution.
